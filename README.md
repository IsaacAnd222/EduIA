# EduIA

EduIA es una aplicación de escritorio orientada a estudiantes. Permitirá consultar información escolar y recibir apoyo académico mediante una interfaz de chat.

## Funciones planeadas

- Identificación de estudiantes por matrícula.
- Consultas de horarios, profesores y salones.
- Consulta de exámenes y calificaciones.
- Avisos escolares.
- Explicaciones y ejercicios académicos.
- Clasificación inteligente de preguntas.
- Interfaz gráfica de conversación.

## Tecnologías

- Python
- CustomTkinter
- SQLite
- Inteligencia artificial
